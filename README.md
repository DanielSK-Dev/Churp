This is Churp a Cryptographic Headless User Routing Protocol. 

Churp uses NAT Transversal to bypass the need for port forwarding for common P2P applications.
In addition, Churp can be used with a very minimal signaling server to create a fully decentralized P2P network.
Churp is written in Python and uses sockets to send json data to peers. 
Churp is designed to be easy to use and easy to integrate into existing applications.
